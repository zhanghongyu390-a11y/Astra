# ASTRA · 星河同行

ASTRA is a fan-inspired personal motivation and journaling PWA.

## Deploy
Import this repository into Vercel. Framework preset: Other; build command: none; output directory: `.`.

## Current prototype scope
- Responsive landing page and daily motivational prompts.
- Private diary stored locally in the current browser (not cloud-synced).
- Basic PWA manifest and service worker.
- Photo community backend is being configured separately in Supabase.

## Important
This repository is public. Never commit private diary data, Supabase service-role keys, passwords, or private photos.
The current frontend is a deployment scaffold; community upload, invite redemption, moderation UI, and cloud diary sync are not yet connected.
